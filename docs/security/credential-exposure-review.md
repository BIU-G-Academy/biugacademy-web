## Scope and method

| Source examined                 | Method                                                                                                                                                                                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Git history of all fetched refs | gitleaks 8.30.1, default rules plus `.gitleaks.toml` (PR #12 CI run); `git log -G` pattern searches for common key shapes (OpenAI `sk-`, Resend `re_`, GitHub `ghp_`, AWS `AKIA`, Meta `EAA`, private keys, PostgreSQL URIs with passwords) |
| Public domain                   | `scripts/site/verify-deployed.mjs` against `https://biugacademy.org` (PR #11)                                                                                                                                                               |
| Repository settings             | Names only: Actions secrets, variables, environments, deploy keys, webhooks, installed apps                                                                                                                                                 |
| Config files                    | `backend/.env.example`, `google-apps-script/Code.gs`, PR #6 `wrangler.toml`                                                                                                                                                                 |

**Not examined:** provider dashboards (Resend, OpenAI, Meta, Cloudflare, database hosting), developers' machines, deployed environment variables, and other repositories that `CROSS_REPO_PAT` may reach. Those need the founder or the account owners.

Note: the repository is **public on GitHub**. Anything ever committed is public, independent of the website exposure ADR-001 addresses.

## Continuous controls

- `secret-scan` (gitleaks, full history) on every PR and push (PR #12).
- Pages artifact content scan for secret-shaped strings and post-deploy exposure check (PR #11).
- `.env` files are git-ignored. The Pages build publishes tracked files only.
