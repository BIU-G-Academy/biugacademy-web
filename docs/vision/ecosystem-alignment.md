# Ecosystem alignment

## Purpose

BIU.G Academy may eventually align advanced technical pathways with contributor readiness for digital infrastructure projects (including CubeShackles-related ecosystems). Today, alignment is **educational and documentary only**.

## Focus areas (planned / progressive)

- Developer and technical literacy orientation
- Compliance-aware language for public-sector and fintech contexts
- Contributor onboarding concepts (documentation, not live economics)
- Angola-first digital infrastructure education

## Boundaries (current)

| Allowed in this repository                   | Not allowed                                   |
| -------------------------------------------- | --------------------------------------------- |
| Read-only education about ecosystem concepts | Wallet, settlement, or fee collection         |
| Accurate, non-promotional references         | Token, investment, or return promises         |
| Contributor pathway documentation            | Storage of credentials or payment data in git |

## Relationship to CubeShackles

CubeShackles and related projects are separate infrastructure efforts. BIU.G Academy does **not** execute financial transactions or production protocol operations from this website repository.

A learning slice may link to the public CubeShackles organization profile as a reading exercise. It does not call a CubeShackles API. The inventory of what was actually readable is in [../operations/learning-mvp.md](../operations/learning-mvp.md).

Future Phase 5 work is described in [../../ROADMAP.md](../../ROADMAP.md).
